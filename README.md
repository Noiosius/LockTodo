# Lock Todo

Galaxy S21을 우선 대상으로 만든 최소형 잠금화면 Todo 앱입니다.

## 현재 기능
- Todo가 없을 때 목록 완전 투명/빈 상태
- 투명 패널 영역 길게 누르기 → 한 줄 Todo 입력
- 왼쪽 `○` → `✓` 애니메이션 후 제거
- 오른쪽 `=` 길게 드래그 → 순서 변경
- 작은 `+` 버튼 표시/숨김, 빈 목록일 때 자동 숨김
- 패널 가로/세로 크기와 위치 조절
- 글자/배경/테두리/체크/핸들/+ 크기 및 투명도 개별 조절
- 체크 제거 속도와 진동 설정
- 부팅 후 자동 서비스 재시작

## 잠금화면 자동 표시
Android 14 이상에서는 설정 화면에서 알림 권한과 `잠금화면 자동 표시 권한`을 허용해야 할 수 있습니다.
기기 제조사/One UI 버전에 따라 전체 화면 알림 동작이 다를 수 있으므로 실제 S21 테스트가 필요합니다.

## 빌드
GitHub Actions의 **Build APK** 워크플로가 `app-debug.apk`를 빌드하고 `LockTodo-debug-apk` artifact로 올립니다.
